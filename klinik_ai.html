Pengaturan Akses AI (Gratis & Hemat Kuota)

Klinik AI berjalan langsung di browser Anda menggunakan API Key Gratis dari Google AI Studio tanpa biaya langganan. API Key hanya tersimpan di perangkat Anda.

Cara Mendapatkan API Key Gratis:
  1. Buka Google AI Studio dan login menggunakan akun Gmail Anda.
  2. Klik tombol biru bertuliskan Create API Key.
  3. Salin teks acak yang muncul, lalu tempelkan pada kotak di bawah ini.
💡 Fitur Penghemat Kuota Otomatis Aktif: Sistem ini otomatis memakai memori sesi server (Stateful Cache) sehingga riwayat chat & file gambar/PDF tidak dikirim berulang-ulang, mengompresi foto soal sebelum dikirim, dan secara bawaan menggunakan Mode Hemat (Gemini 3.5 Flash-Lite) agar kuota gratis Anda jauh lebih awet.

Pahami Etika & Formula Prompting

Peringatan Etika Penggunaan AI:
1. AI adalah Asisten, Bukan Ahli Matematika Mutlak. Meskipun tersedia fitur Verifikasi Hitungan, guru tetap wajib memeriksa ulang kunci jawaban dan kelayakan pedagogis soal.
2. Jaga Privasi. Jangan pernah memasukkan nama asli murid, nilai rapor, atau data pribadi sekolah ke dalam kolom chat AI.

Untuk mendapatkan jawaban AI yang sesuai dengan Standar TKA, Anda perlu meracik perintah (prompt) yang jelas. Gunakan 3 pilar formula ini saat Anda mengetik:

1. Peran & Domain

Tentukan apakah Anda ingin fokus di Aljabar, Bilangan, Geometri, atau Data Peluang.

2. Konteks/Konten

Sebutkan apakah ini soal murni (Intra-Matematika) atau soal cerita kontekstual (Masalah sehari-hari).

3. Tugas & Level

Minta AI menyesuaikan apakah ini untuk Pemahaman (L1), Aplikasi (L2), atau Penalaran (L3).
